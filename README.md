# E-Commerce Sales Analysis | Excel

## Project Overview

This project analyzes e-commerce sales data using Microsoft Excel to identify sales trends, product performance, customer insights, and overall business performance.

The project includes data analysis, calculations, Pivot Tables, and interactive dashboards to present key business insights in an easy-to-understand format.

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization
- Interactive Dashboards

## Dataset

The project contains 6 datasets covering the data required for the e-commerce sales analysis.
